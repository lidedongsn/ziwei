# 开发约定

## 模块职责

- `src/extension` 只处理 Chrome 生命周期与浏览器入口，不引用页面 DOM。
- `src/shared` 放可被多个工具复用的逻辑，当前只有主题。实际出现复用需求时再抽取组件。
- `src/tools/<name>` 按工具组织。纯数据转换与 DOM 交互分离，纯逻辑通过 Node.js 测试。
- `src/main.js` 是页面入口。负责公共主题、工具导航以及 JSON、大小转换器和 Base64 编解码的启动，不显示尚未实现的工具入口。
- `index.html` 定义静态页面结构，所有执行代码使用本地外部模块，遵守扩展 CSP。

新增时间戳、Base64 等工具时，在 `src/tools/timestamp`、`src/tools/base64` 中实现纯转换模块、视图与控制逻辑。随后接入页面入口和工具导航。当前各工具只初始化一次，切换时隐藏工作台，保留内存中的输入和结果；JSON 快捷键仅在其工作台可见时生效，拖放事件限定在 JSON 工作台内。新增工具沿用此模式；若改为动态挂载，则需暴露初始化和销毁函数，销毁时解除监听并取消定时器。

## 保持的行为

JSON 使用原始标量 token，不能改为直接解析成 JavaScript 数字后再序列化，否则大整数与长小数会丢失精度。用户输入只通过文本节点展示，不拼接为 HTML。

输入结束 300 毫秒后自动更新，输入法组合期间不处理；自动校验不改变光标位置。树形默认开启，缩进设置同步作用于元数据和树形。选择字段时只突出本行、祖先字段和配对括号，折叠通过箭头独立操作。

不保存用户输入历史，不发起外部请求。主题偏好保存在本地，网页选中的文本通过临时 session storage 传入工具页并在读取后删除。

## 检查与交付

图标原图位于 `assets/icon-source.png`；运行时使用 `src/assets/icons/` 中的 16、32、48、128 像素透明 PNG。更换图标时同时更新各尺寸，保持原始比例。`manifest.json` 配置扩展图标，`index.html` 配置页面标识和标签页图标。构建只包含运行时尺寸，不包含原图。

提交前运行 `npm run build`，检查、测试失败时不会继续生成新产物。产物位于 `dist/ziwei`，可在扩展管理页直接加载。不要手动修改生成目录。

涉及视图的修改还需在 Chrome 手工检查：

1. 粘贴包含嵌套数组、大整数、中文和转义字符串的 JSON，确认自动格式化及默认树形。
2. 逐字输入无效 JSON，确认显示错误且不抢光标；修正后恢复结果。
3. 切换缩进、排序、元数据与树形，确认输出一致。
4. 点击字段、父字段和括号，确认祖先高亮；检查箭头折叠和 Esc 取消。
5. 搜索、复制反馈、下载、文件导入、明暗主题及窄窗口滚动。
6. 检查工具栏扩展图标和网页右键入口；连续打开两份选中文本，确认互不串数据。

自动测试目前覆盖解析与扩展入口，不代表浏览器视觉验收。原生 HTML/CSS 不经过编译，修改后需刷新页面。

大小转换验收：输入 1 MB 应得到 1048576 B，输入 1 GB 应得到 1024 MB；检查任意单位输入、小数、零、大整数、负数和清空联动。切换工具应保留输入，转换器中 Ctrl / ⌘ + Enter 不应触发 JSON；检查明暗主题和窄窗口布局。

Base64 验收：左侧输入中文和 Emoji，右侧自动编码；编辑右侧 Base64，左侧应自动解码；输入非法 Base64 或非 UTF-8 数据应提示错误并清空旧结果。检查复制、清空、切换工具保留输入和刷新恢复 Base64 页签。
